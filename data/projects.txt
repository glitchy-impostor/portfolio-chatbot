OFF-BALL RUN DEFENSIVE ANALYSIS
Type: Sports Analytics Research (Featured)
Technologies: Python, pandas, SciPy

Analyzed Metrica Sports tracking data to measure defensive reactions to off-ball runs in soccer using a matched-control methodology. The analysis found a significant defensive disruption effect (Cohen's d = 1.42, p < 0.0001), demonstrating strong methodological rigor and attention to statistical validation. The project examines how defenders react to attacking player movement even when those players don't have the ball.

This project showcases Krish's ability to work with complex sports tracking data and develop novel, statistically rigorous analytical approaches.

RAG CODE GENERATOR
Type: AI/ML Software Project
Technologies: Python, ChromaDB, Docker, OpenAI API, Local LLMs

The RAG Code Generator is one of Krish's most substantial projects, developed during his internship at Whiteklay Technologies. It is an AI-powered code generation and reuse platform totaling nearly 6,000 lines of Python code.

Key features:
- Retrieval-Augmented Generation (RAG) architecture for intelligent code suggestions
- ChromaDB vector database for storing and retrieving code embeddings
- Docker-based sandboxed execution for safely running generated code
- Support for both OpenAI models and local language models
- Enterprise-focused design for code reuse and standardization, adopted as a company-wide service across multiple engineering teams

This project demonstrates expertise in AI/ML systems, vector databases, and building production-ready software.
